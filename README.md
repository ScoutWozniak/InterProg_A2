# InterProg_A2

## Dependencies:
Requires Visual Studio 2022 To Be Installed

## How To Play:
The aim of the game is to unlock the final exit door.  To do this you need to route power through a grid by connecting different objects together

### Controls:
W, A, S, D / Left Stick - Movement
Mouse / Right Stick - Looking
Left Click / Right Trigger - Connect Wires
Esc / P / Start - Pause
R / Select - Restart
**NOTE: UI does not support controller input currently!**
